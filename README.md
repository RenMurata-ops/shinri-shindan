# 真理診断（Shinri Shindan）

独自開発の「真理探究占星」による高精度性格診断システム

## プロジェクト概要

13種類の占術を統合し、Claude APIで統合診断を生成する完全無料の性格診断ツールです。

### 主な機能

- **6問の質問フロー**: ユーザーフレンドリーなステップ式フォーム
- **第一段階診断**: アーキタイプ、エレメント、才能領域、相性診断
- **VIP診断（第二・第三段階）**: 深層心理、人生のテーマ、12の波動、3年間の運勢予測
- **シリアルコード発行**: LINE公式アカウント連携による深掘り診断へのアクセス

## 技術スタック

- **フロントエンド**: Next.js 15, TypeScript, Tailwind CSS, Framer Motion
- **バックエンド**: Next.js API Routes
- **データベース**: Supabase (PostgreSQL)
- **AI**: Claude API (Anthropic)
- **デプロイ**: Vercel

## セットアップ手順

### 1. 依存関係のインストール

```bash
npm install
```

### 2. Supabaseデータベースのセットアップ

`supabase-schema.sql`をSupabaseダッシュボードのSQL Editorで実行してください。

### 3. 開発サーバーの起動

```bash
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開きます。
