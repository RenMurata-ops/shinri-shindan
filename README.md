# 真理診断 (Shinri Shindan)

深層心理を探り、真理へと導くスピリチュアルな診断プラットフォーム

## Features

- スピリチュアルなデザイン
- レスポンシブ対応（モバイル完全対応）
- グラスモーフィズムUI
- アニメーション効果

## Tech Stack

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- Lucide Icons

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
